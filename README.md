# Chatter

A clean landing page for Chatter — a platform where writers and readers can share text-based content, connect with like-minded people, and engage in meaningful discussions.

## About the Project

This is a static website built with HTML and CSS. It includes:

- A responsive header with navigation and auth buttons
- Hero section introducing Chatter
- About section
- Feature cards (Analytics, Social interactions, Content creation)
- Testimonial section
- Final call-to-action
- Footer with useful links
